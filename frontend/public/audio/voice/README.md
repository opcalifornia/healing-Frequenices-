# Recorded voice cues

Drop recorded MP3s here and the breathing player uses them instead of the
device's built-in voice:

| File | Say |
|---|---|
| `in.mp3` | "Breathe in" |
| `top.mp3` | "Sip in a little more" |
| `hold.mp3` | "Hold" |
| `out.mp3` | "Breathe out" |
| `rest.mp3` | "Hold" (after breathing out) |
| `done.mp3` | "Well done. Let your breath return to normal." |

Record in a quiet room, speak slowly and softly, leave about 0.2 s of
silence at the start and trim the end tightly. Export mono MP3 at 128 kbps.
See docs/RECORDING_GUIDE.md.
